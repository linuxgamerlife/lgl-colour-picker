Build a simple Qt 6/C++ application for picking colours on screen and copying
their values in ready-to-paste formats.

## v1.0.x MVP

- Screen colour picking.
- Colour preview.
- HEX, RGB, and RGBA output.
- One-click clipboard copy.
- Portal-first Wayland support, with compositor/helper fallbacks where
  available.
- Native Qt styling aligned with `lgl-emoji-picker`.

## Future Ideas

- Smart paste detection for pasted colour values.
- Expanded format conversion.
- Enlarged hover preview.
- Original/current colour comparison.
- Colour contrast checking for readability.
